What this is

SSEF is a research prototype built for a final-year BSc (Hons) Computing dissertation (NIBM / Coventry University). It is not a commercial service.

What is stored

  • Your username and a hash of your password (never the password itself).
  • A session cookie that keeps you signed in for 8 hours.
  • For sign-in and sign-up limits, your IP address is held in memory and cleared when the server restarts.
  • The web server (nginx) keeps standard access logs, which include IP addresses.
  • Your interface language and theme choices are saved in your own browser, not on the server.

Your stories

A story you paste is processed in memory to compute scores and is not saved to disk.

For standard evaluation, the story text is discarded immediately after the response is sent. For background fluency jobs, the story text is processed in memory and not retained; only the resulting scores remain in server memory until the server restarts.

What is not done

No e-mail address is collected. The application runs on a server hosted by Amazon Web Services. No analytics, no advertising and no other third-party services are used. Stories are not sent to any external API. Data is not shared or sold.

Deleting your account

Contact the researcher at vdeshan044@gmail.com to delete your account.

Security

This is prototype access control, not production security. Use a password you do not use elsewhere.
